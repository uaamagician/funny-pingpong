# 角色、球拍、球、場地 設計提案（待評估）

> 狀態：**第一版已實作**（十個角色、球拍、球、場地效果、技能）。數值刻意調得很溫和；
> AI 對手隨機挑角色（只用基礎數值與被動，不放技能）。節奏舞台與火山場地尚未做。

## 1. 五項數值（1–10）怎麼影響比賽

| 數值 | 影響 | 換算（5 = 現在的手感） |
|---|---|---|
| 力量 | 球速 | 球速 ×(0.85 + 0.03×力量) |
| 旋轉 | 旋轉強度（上旋、下旋、側旋） | 旋轉 ×(0.5 + 0.1×旋轉) |
| 控球 | 落點誤差 | 誤差 ×(1.5 − 0.1×控球) |
| 時機 | 「完美」時機的寬度 | 完美區間 ±(0.12 + 0.016×時機) |
| 範圍 | 綠色擊球圈大小 | 半徑 ×(0.7 + 0.06×範圍) |

**技能槽**：完美擊球 +25%、普通擊球 +10%、長來回額外加成。滿了畫面左下出現技能鈕，點一下啟動。
**被動**：每個角色一個，一直有效。

## 2. 十個角色

數值順序：力量／旋轉／控球／時機／範圍（總和大約 26–28，強項越強弱項越弱）。

| # | 角色 | 定位 | 力/旋/控/時/範 | 被動特長 | 技能 |
|---|---|---|---|---|---|
| 1 | 麻糬君 | 均衡、新手角色 | 5/5/5/5/5 | **Q彈**：連續完美擊球，時機圈每次再放寬 10%（最多 3 層） | **麻糬護體**（5 秒）：球落桌後彈得又高又慢，你好接、對手難殺 |
| 2 | 旋風大叔 | 旋轉大師 | 4/10/5/4/4 | 旋球弧度 +30%、落桌偏轉 +50% | **龍捲風**：下一球極強側旋，落桌後橫跳約 60 cm |
| 3 | 鐵拳阿嬤 | 殺球 | 10/3/4/4/5 | 殺球球速 +15%、殺球震動更大 | **奶奶的怒吼**：下一球一定是殺球（不用球在高處），對手失誤率 +60% |
| 4 | 小冷機器人 | 精準控球 | 5/3/10/6/4 | 預測落點標記更小更準 | **雷射校準**（5 秒）：球一定落在你滑動指的位置，誤差為零 |
| 5 | 忍者切切 | 切球防守 | 3/7/8/5/5 | 切球下旋 +30%、落桌後幾乎停住 | **煙霧彈**：對手下一次回球失誤率 +35% |
| 6 | 彈簧小子 | 時機寬容 | 4/4/4/10/6 | 偏早／偏晚的懲罰減半 | **彈跳步**（5 秒）：擊球圈 ×1.6、完美區間 ×2 |
| 7 | 吊球貴婦 | 欺敵吊球 | 2/6/8/6/6 | 吊球可落在更貼網的位置 | **花式吊球**：下一球落桌後朝反方向彈跳 |
| 8 | 爆走阿伯 | 高風險高報酬 | 9/8/2/3/4 | 完美擊球威力 +25%，但失誤多 | **暴走**（5 秒）：力量、旋轉再 +40%，落點誤差 ×2 |
| 9 | 幽靈小白 | 隱形球 | 5/6/6/5/5 | 球過網後半透明閃爍，對手失誤率 +8% | **隱形球**：下一球過網後完全隱形到落桌，對手失誤率 +40% |
| 10 | 章魚老闆 | 守備範圍王 | 4/4/5/5/10 | 擊球圈特別大，很難空揮 | **八爪連擊**（5 秒）：擊球圈 ×2，並帶雙段殘影特效 |

外型：全部是搞笑抽象風，每個角色一套預設臉型與服裝（大小眼、頭大小、顏色、特殊配件），之後仍可在「改造型」微調。
解鎖：預設開放 1、2、3，其餘之後用寶箱／任務解鎖（或你想全開放也可以）。
AI 對手也會隨機挑一個角色，用同一套數值與技能，所以每場對手風格不同。

| 球拍 | 效果 |
|---|---|
| 標準木拍 | 無加成 |
| 進攻碳纖拍 | 力量 +2、控球 −1 |
| 防守長顆粒拍 | 下旋 +2、力量 −1、控球 +1 |
| 旋轉膠皮拍 | 旋轉 +2、時機 −1 |
| 控制拍 | 控球 +2、力量 −1 |
| 平底鍋（搞笑） | 力量 +3、控球 −3、範圍 +1，擊球聲「噹！」 |

| 彩虹魔法拍（稀有） | 全部 +1；完美擊球 20% 機率暴擊（球速 +20%、彩虹軌跡） |

## 4. 球（7 種）

| 球 | 效果 |
|---|---|
| 標準白球 | 無加成 |
| 鉛球 | 飛得慢 10%，但落桌後加速衝刺 |
| 泡泡球 | 重力 −20%（會飄）、旋轉效果 +30% |
| 彈力球 | 落桌彈得更高，容易殺球 |
| 火球 | 球速 +10%，殺球拖火焰；控球 −1 |
| 西瓜球 | 球變大 ×1.5（好打好看），球速 −15% |
| 幽靈球（稀有） | 飛行中週期性半透明閃爍 |

## 5. 場地效果（6 個）

| 場地 | 效果 |
|---|---|
| 紫夜競技場 | 基準場地；完美擊球時全場閃光、噴彩帶 |
| 夕陽海灘 | **海風**：橫風每 10 秒換方向，球飛行時被吹偏，畫面有風向箭頭 |
| 太空站 | **低重力**：重力 ×0.7，球飛更高更久，回合更長 |
| 冰原 | **滑桌面**：落桌後球速 +8%，下旋效果減半 |
| 火山 | **地震**：每 8 秒桌面震動 2 秒，時機圈抖動 |
| 節奏舞台 | **踩拍**：背景有節拍，踩準拍子擊球技能槽額外 +15% |

## 6. 出賽準備畫面

主選單 → AI 對練 → **出賽準備**：橫向滑動選角色（顯示 5 項數值長條、被動、技能說明）→ 下方分頁選球拍／球／場地 → 開始。
選擇會記住，下次直接帶入。

## 7. 實作順序（每一步都單獨 commit 並推上 GitHub）

1. 資料檔：角色、球拍、球、場地效果（純資料）
2. 數值接進擊球模型，並用 `npm run lab` 驗證各角色手感差異
3. 出賽準備畫面與存檔
4. 技能槽與前 3 個角色的技能
5. 其餘 7 個角色的技能
6. 十個角色的預設外型
7. 球拍與球的效果與外觀
8. 場地效果（風、低重力、冰、地震、節拍）
9. AI 對手使用角色與技能
10. 平衡測試（用實驗腳本檢查各角色強弱是否接近）
