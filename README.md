# 乒乓大亂鬥（暫名）

手機直式乒乓球遊戲：用手指滑動殺球、旋球、吊球、切球，搞笑抽象的 3D 角色。
參考對象：[matdrive.app](https://matdrive.app)。

## 執行

```bash
npm install
npm run dev      # 開發（同網段手機可直接開 Network 網址）
npm run build    # 產生 dist/
```

## 操作

| 動作 | 手勢 |
|---|---|
| 發球 | 向上滑，左右決定方向 |
| 擊球 | 球彈起後往前滑，時機越準越準確 |
| 殺球 | 球在高處時快速猛滑 |
| 旋球 | 滑動時劃出弧線（左弧／右弧） |
| 吊球 | 輕輕短滑 |
| 切球 | 向下滑 |

桌機測試：空白鍵 = 一般擊球。

## 擊球系統

- **點一下也能打**：球進入綠圈時，在球上點一下＝平擊（發球時＝一般發球），點得越靠近球心越準；滑動才有殺球、旋球、切球、吊球。
- **球種**：正手／反手 × 平擊、上旋拉球、旋球（左／右）、切球、吊球、殺球、快撥（反手）、挑球（低球）。
- **正手／反手**（不顯示在畫面上，只影響手感）：球在身體右側用正手（力量大、能殺球），左側用反手（較穩、改用快撥）。
- **每次滑動都有旋轉**：向前滑＝上旋、向下滑＝下旋、劃弧線＝側旋；滑得越快旋轉越強。
- **時機**：綠圈外有時機圈，縮到跟綠圈一樣大＝最佳。偏早球偏左變短、偏晚球偏右變深，太差可能掛網或出界。
- **發球規則**：球要先落在自己這半桌，彈起後過網，再落在對方半桌。直接飛過去、在自己半桌彈兩次、掛網、出界都算失誤。
- **失誤不是隨機的**：球沒進一定有原因，全由你的操作決定（畫面不會寫出原因）：
  - 時機：太早 → 球偏左、太短、容易掛網；太晚 → 球偏右、太深、容易出界。
  - 擊球點：滑過球時要碰在**甜蜜點**（綠圈中間的虛線圈）；從球的邊緣擦過 → 球偏向那一側；
    球落在這一劃的**起手段**（還沒加速）→ 力量不足、掛網；落在**收尾段**（揮過頭）→ 飛太遠、出界。**一劃的中段碰到球最準。**
  - 冒險的球（殺球、快撥、吊球）會放大同樣的偏差；穩的球（平擊、切球、挑球）比較寬容。
  - AI 用同一套規則，只是擊球點與時機的偏差由難度決定。
- **連擊與回饋**：連續完美擊球會累積連擊，擊球音調隨之升高；手機會震動。
- **實驗與調整**：`npm run lab` 用擊球模型跑一輪實驗（球種、落點、弧度、時機、AI 球種）；
  `npm run lab:compare` 與上一版對照。所有手感數值集中在 `src/tuning.js`。

## 結構

- `src/physics.js` 球的物理與擊球解算（旋轉、過網補償）
- `src/shots.js` 擊球模型（滑動 → 球種、旋轉、落點；AI 球種；試打模擬）
- `src/tuning.js` 手感與效果數值
- `scripts/shot-lab.mjs` 擊球實驗室
- `src/character.js` 程式生成的搞笑角色（外觀全由一份 config JSON 決定）
- `src/main.js` 場景、規則、手勢、AI、主迴圈
- `src/audio.js` WebAudio 合成音效
